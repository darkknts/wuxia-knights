# 01. 게임 개요

> 문서 상태: 기획 초안 — 확정된 사항과 미정 사항을 구분한다.

## 1. 프로젝트 기본 정보

- 게임명: 무협기사단
- 영문명: Wuxia Knights
- 장르: MMORPG
- 개발 단계: 1차 판타지 세계, 2차 무역 세계
- 기획·협의 언어: 한국어

## 2. 핵심 콘셉트

플레이어는 여러 직업 중 하나를 선택해 캐릭터를 육성하고, 사냥과 퀘스트를 통해 경험치와 아이템을 획득하며 성장하는 MMORPG를 플레이한다.

## 3. 세계관 구성

### 1차: 판타지 세계
- 하나의 큰 대도시를 중심 거점으로 설정한다.
- 대도시 주변에 여러 소도시와 사냥 지역을 배치한다.
- 초기에는 복잡한 세력·정치 구도를 두지 않는다.
- 전체 분위기는 밝은 판타지풍으로 설정한다.

### 2차: 무역 세계
- 판타지 세계와 구분되는 별도의 세계로 계획한다.
- 구체적인 세계관과 시스템은 판타지 세계 기획 이후 협의한다.

### 두 세계의 연결 배경
- 두 세계는 처음부터 서로의 존재를 알거나 전쟁을 벌이고 있지 않다.
- 정체를 알 수 없는 균열 또는 공간 이상 현상이 발생한다.
- 이 현상을 계기로 두 세계 사이의 흔적과 이동 가능성이 나타나기 시작한다.
- 균열의 원인과 배후는 추후 스토리 기획에서 결정한다.

## 4. 핵심 플레이 방향

- 캐릭터 생성 후 직업을 선택한다.
- 필드에서 몬스터를 사냥하고 퀘스트를 수행한다.
- 경험치를 얻어 레벨업하고 장비와 스킬을 통해 성장한다.
- MMORPG에 맞춰 다중 사용자 접속과 상호작용을 고려한다.

## 5. 개발 범위 원칙

- 1차 개발은 판타지 세계의 MMORPG 핵심 기능에 집중한다.
- 2차 무역 세계는 후속 확장으로 분리한다.
- 그래픽 스타일과 카메라 시점은 아직 확정하지 않는다. 픽셀 아트/2.5D 및 탑뷰/쿼터뷰의 제작 가능성을 테스트한 뒤 결정한다.
- 미확정 아이디어를 확정 요구사항으로 취급하지 않는다.
