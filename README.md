# 무협기사단 (Wuxia Knights)

방치형 RPG **무협기사단 (Wuxia Knights)** 프로젝트입니다.

## 게임 방향
- 2등신 픽셀 아트
- 동양 무림 vs 서양 기사단
- 자동 전투와 방치 보상
- 직업: 무사, 궁수, 기사, 아처
- 스킬 사용 시 사용자 지정 말풍선
- 캐릭터/몬스터/맵/스킬 데이터를 분리하여 확장 가능한 구조

## 초기 캐릭터
### 동양
- 무사: 청룡언월도, 듬직한 장수 스타일
- 궁수: 동양 궁사 스타일

### 서양
- 기사: 검과 방패를 사용하는 중장갑 기사
- 아처: 서양식 활을 사용하는 원거리 딜러
