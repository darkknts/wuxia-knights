# Character Asset Rules

모든 캐릭터 파츠는 동일한 좌표계로 제작합니다.

- 기본 캔버스: 64x64 px
- 기준점: bottom-center
- 픽셀 퍼펙트: image smoothing off
- 레이어 순서: body → face → hair → clothes → armor → gloves → boots → weapon → shield → cape → effect → speech
- 투명 배경 PNG 권장
- 장비만 교체해도 남/여 캐릭터 모두에 적용할 수 있도록 동일한 기준 좌표를 사용

## 디자인 비율
- 머리 약 50%
- 몸 약 30%
- 무기/장비 약 20%

## 현재 확정된 직업 무기
- 무사: 청룡언월도
- 궁수: 활
- 기사: 검 + 방패
- 아처: 활
